# Contributing

Thanks for helping make project handoffs clearer.

## Before opening a pull request

1. Keep the app dependency-free and make sure card contents stay in the user's browser.
2. Add or update tests for data-model behavior and keep English and Chinese copy in sync.
3. Run `npm run check` and `npm test` with Node.js 22 or newer.
4. Describe the user-visible behavior and any privacy or backup implications.

Please do not include real project cards, private file paths, credentials, or personal data in examples or screenshots.
